# تقویم شمسی — نمایش تاریخ روی صفحهٔ قفل

یک برنامهٔ سبک اندروید به نام **Persian Calendar** که یک **نوتیفیکیشن دائمی** با تاریخ روز نشان می‌دهد:

- خط اول: تاریخ هجری شمسی با روز هفته — مثل **سه‌شنبه ۱۴ مهر ۱۴۰۵**
- خط دوم: تاریخ میلادی — مثل **Tue, 6 Oct 2026**

نوتیفیکیشن به‌صورت `PUBLIC` علامت‌گذاری شده، بنابراین **روی صفحهٔ قفل هم** دیده می‌شود و وقتی گوشی باز است، با کشیدن سایه‌برنامه از بالای صفحه در دسترس است.

## امکانات

- ✅ سازگار با **اندروید ۸ (Oreo, API 26)** به بالا — تا اندروید ۱۴ و ۱۵
- ✅ تقویم نجومی مطابق **تقویم رسمی ایران** (با احتساب سال‌های کبیسه؛ دقت تا سال ۱۶۳۳ شمسی)
- ✅ ارقام فارسی، بدون نیاز به هیچ کتابخانهٔ جانبی
- ✅ همیشه فعال: سرویس Foreground + اجرای خودکار بعد از **ری‌استارت گوشی** و بعد از **آپدیت برنامه**
- ✅ به‌روز شدن خودکار تاریخ در نیمه‌شب (و در تغییر ساعت/منطقهٔ زمانی)
- ✅ لمس نوتیفیکیشن → باز شدن برنامه
- ✅ دکمهٔ «مستثنا کردن از بهینه‌سازی باتری» برای ماندگاری بیشتر

## نصب سریع

اگر فایل APK آماده شده را دارید، فقط آن را روی گوشی منتقل و نصب کنید
(اجازهٔ «نصب از منابع ناشناس» لازم است). سپس یک‌بار برنامه را باز کنید و دکمهٔ
**«نمایش تاریخ روی صفحهٔ قفل»** را بزنید.

## ساخت از سورس

### روش ۱: اندروید استودیو
1. پوشهٔ پروژه را در Android Studio باز کنید (Gradle و SDK را خودکار دانلود می‌کند).
2. از منوی `Build → Build Bundle(s)/APK(s) → Build APK(s)` یک APK بگیرید.

### روش ۲: خط فرمان
```bash
./gradlew assembleRelease
```
خروجی: `app/build/outputs/apk/release/app-release.apk`

> **نکتهٔ شبکه:** اگر `dl.google.com` برای شما باز نیست (مثلاً در ایران)، این پروژه
> از قبل طوری تنظیم شده که آینه‌های هوآوی/آلیون را قبل از مخازن گوگل امتحان کند و
> بدون VPN بیلد می‌شود.

## اگر تاریخ را روی صفحهٔ قفل نمی‌بینید

1. **دسترسی نوتیفیکیشن** (اندروید ۱۳ به بعد): تنظیمات ← برنامه‌ها ← Persian Calendar ← Notifications را روشن کنید. خود برنامه هم اولین بار این دسترسی را می‌پرسد.
2. **نمایش محتوا روی قفل صفحه**: تنظیمات گوشی ← قفل صفحه (یا Sound) ← «On the lock screen / نمایش نوتیفیکیشن‌ها روی صفحهٔ قفل» را روی **Show all content / نمایش تمام محتوا** بگذارید.
3. **بهینه‌سازی باتری**: در خود برنامه دکمهٔ «مستثنا کردن از بهینه‌سازی باتری» را بزنید.
4. **گوشی‌های شیائومی (MIUI)، هوآوی، اوپو/ویوو و سامسونگ**: در تنظیمات، «اجرای خودکار / Autostart» را برای این برنامه فعال کنید؛ وگرنه این لایه‌ها سرویس‌های پس‌زمینه را می‌کشند.
5. برنامه را **Force Stop نکنید** — با Force Stop اندروید همه‌چیز (از جمله نوتیفیکیشن) را می‌بندد و تا باز شدن دوبارهٔ برنامه برنمی‌گردد. بستن از لیستِ برنامه‌های اخیر مشکلی ندارد.

## ساختار پروژه

```
app/src/main/java/com/taghvim/lockcalendar/
├── JalaliDate.kt        ← الگوریتم تبدیل میلادی→شمسی (تقویم نجومی)
├── DateLines.kt         ← ساخت متن دو خط (شمسی/میلادی)
├── CalendarService.kt   ← سرویس Foreground و نوتیفیکیشن دائمی
├── BootReceiver.kt      ← اجرای خودکار بعد از ری‌استارت/آپدیت
└── MainActivity.kt      ← صفحهٔ سادهٔ فعال‌سازی و پیش‌نمایش تاریخ

app/src/main/res/layout/
├── notification_date.xml       ← نمای فشردهٔ نوتیفیکیشن
└── notification_date_big.xml   ← نمای باز‌شده (روی صفحهٔ قفل)
```
